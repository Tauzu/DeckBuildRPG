## 1. ねらい

今のカードと敵の効果は、耐性・手札を捨てさせる・呪い・武器の能力など「数値寄り」のものが中心。進軍ルートの **位置と時間** に触れる効果はない。

新ステージでは、ルートを「盤面」として扱う効果を加え、手番の使い方（今は倒すか、村で育てるか）に **敵の足止め・並びの操作** という第3の判断を足す。

- 追加するのは「凍結・後退」の効果、「護衛・分裂・疾走」の敵能力、新英雄1種、新武器1種、新ボス。
- **罠カードは今回は見送る**（8章）。新しいカード種別・設置の操作・画面が必要で重いため、あとで改めて検討する。
- 既存の仕組み（進軍・公開・撃破・ボスのダメージが残る）は変えない。

## 2. 新しい効果：凍結と後退

| 効果 | 内容 |
|---|---|
| 凍結 | 選んだ敵1体は、**次の進軍で動かない**（移動も進軍時の能力もなし）。進軍が1回終わると解ける。同じ敵に重ねがけしても1回分 |
| 後退 | 選んだ敵1体を、ルートで **1マス後ろ（1マス目側）に戻す**。1マス目の敵には効果がない |

- どちらもボスには効かない（ボスは凍結・後退を受けない）。
- 使い方は2つ：英雄の村効果（集落を訪れたとき）と、武器の能力（戦闘のとき。4.3）。
- 凍結した敵は、見た目で分かるようにする（ルート上のカードに氷のマーク）。
- 狙い：「危ない敵を止めておいて、今手番は育成に回る」「後退でルートに空きを作る」など、テンポの管理ができる。

### 仕様の細かい点（案）
- 凍結・後退は、対象の敵を選ぶ入力待ち（`pending`）が必要になる。進軍ルートに敵がいなければ何も起きない。
- 凍結中の敵が撃破されたら、そのまま取り除かれる（特別な処理はなし）。
- 進軍を丸ごとやめるラウンド（全員が撃破したラウンド）では、凍結は解けずに持ち越す。

## 3. 新しい敵能力

| 能力 | 内容 | 戦略への影響 |
|---|---|---|
| 護衛 | 護衛を持つ敵（以下G）は、**同じマスの護衛を持たない敵** と **1つ後ろのマス（1マス目側）の敵** を守る。守られた敵は、Gを倒すまで攻撃の対象に選べない（G自身は、別のGに守られていなければ選べる） | 「楽な敵から倒す」ができない。倒す順番を考える |
| 分裂 | この敵への攻撃が撃破に失敗したとき、**1体につき1回だけ**、ルートの1マス目に小スライムを1体出す | 中途半端な火力が裏目に出る。一撃で倒せる編成を整えたくなる |
| 疾走 | 進軍のとき、1マスではなく **2マス** 進む。集落を超える場合は到達として扱う | 優先して倒すか、凍結・後退で対処する |

- 護衛の判定は、敵Eがマスtにいるとき、「マスt+1にいるG」または「マスtにいて、Eが護衛を持たない場合のG」が1体でもいればEは守られる、とする。同じマスのG同士は守り合わないので、行き詰まらない（一番集落に近いGは必ず選べる）。
- 小スライムは敵の山札とは別に生まれる（山札の枚数は変えない）。経験値0・分裂しない。1マス目に何体いてもよい。
- 分裂の回数は、スライム1体ごとに「分裂済み」を記録して数える。
- 危険度の「魔物の生命力+」は小スライムにも足す。

## 4. 新カード

### 4.1 英雄：氷術師（`frost`）

Lv1〜3。魔法攻撃に寄せ、村効果で凍結・後退を使う（値は仮）。

| Lv | 物理 | 魔法 | 村効果 | 次の経験値 |
|---|---|---|---|---|
| 1 | 0 | 2 | 後退 1回 | 2 |
| 2 | 0 | 4 | 凍結 1回 | 4 |
| 3 | 0 | 6 | 凍結 1回 ＋ 後退 1回（組み合わせ） | なし |

- 攻撃力は魔法使い（3／5／8）より低くして、効果の分を差し引く。
- 金価値は 1／1／2、コストは 4／7／10、在庫は 4／3／2 枚（既存の英雄と同じ）。

### 4.2 武器：霜の杖（`weapon_frost`）

- 魔法+2。能力 `chill`：**場に出したこの武器を使った攻撃が撃破できなかったとき、その敵を凍結する**。
- 倒せなかったときの保険になる。氷術師に装備しなくても効く（装備した英雄は問わない）。ボスには効かない。
- 金価値1、コスト4、在庫4枚。

## 6. ボス：雪の女王

- 生命力：1／2／3／4人で **28／48／80／124**（魔竜の40／69／113／165より低い。物理半減のため、同じ生命力だとずっと厳しくなる。7章のシミュレーターの結果で決めた）。物理半減。経験値10、金価値5。凍結・後退は効かない（ボス全般）。
- **公開時（号令）**：ルート上の他の敵すべてを1マス進める。凍結中の敵は凍結が解ける。**5マス目の敵は動かない**（号令で集落に到達はしない）。
  - 女王が出た時点で、積み上げた足止めが崩れる。「女王が来る前に、足止めに頼らず敵を減らしておく」判断を迫る。
- **進軍時（吹雪）**：次の手番のプレイヤーが手札を1枚捨てる（既存の`discardHand`・`target: next`）。

## 7. ステージの設定

| 項目 | 内容 |
|---|---|
| id / 名前 | `stage5` / 凍てつく峠 |
| 解放 | ステージ4をクリアすると遊べる（今の「前のステージをクリア」の仕組みのまま） |
| 背景 | 新規のドット絵（雪の峠、夜明けの空）が要る。`backdrops.ts` に追加 |
| 英雄 | 騎士、魔法使い、狩人、僧侶、吟遊詩人、氷術師（**盗賊は出ない**） |
| 食料・武器 | ステージ4までのもの＋霜の杖 |
| 敵 | 5章の表のとおり |
| ボス | 雪の女王 |
| 人数 | 1〜4人 |

- **画面**：英雄在庫は6束のまま。氷術師が盗賊の枠に入るので、在庫の画面は変えない（7束にすると、折り返しでスマホの在庫が縦に伸びるため）。金を稼ぐ盗賊がいない分、金の確保が少し難しくなる。この影響はシミュレーターで確認する。
- ステージ5は **追加の挑戦ステージ**。魔竜の巣（ステージ4）が本編の最後であることは変えない。
  - ステージを指定しなかったときの既定は、今は「最後のステージ」。ステージ5を足すとこれが変わるので、`stages.json` に `extra: true` を持たせ、既定は「extra でない最後のステージ」（ステージ4）にする。
  - ステージ4をクリアしたときの「次のステージへ」は、ステージ5を指す（そのまま）。
- 危険度（`dangers.json`）はステージ5にもそのまま使う。

## 8. 後回しにする案：罠カード

- 村で買って、集落訪問中に進軍ルートのマスへ設置し、敵が来ると発動する使い切りのカード。
- 戦う・育てる・**仕掛ける**の3択になり、マルチで「ボスの通り道に罠を集める」協力ができる。
- 見送る理由：新しいカード種別、設置の操作（`placeTrap`）、ルート上の表示が必要で、実装の範囲が大きい。
- 今回の凍結・後退を試したあとに、必要なら改めて検討する。

## 10. バランスとテスト

- 凍結・後退が強すぎて、敵が永久に集落に着かない状態にならないか（シミュレーターで確認）。
- 分裂が、ソロで手数が足りず詰みにならないか。
- 護衛が、特定の人数で攻略不能な並びを作らないか。
- 女王の号令で、足止めに頼った場合に敗北がちょうどよく出るか。
- テストの追加：凍結の持ち越し、後退（1マス目では何も起きない）、護衛の攻撃対象の制限、分裂の回数上限、疾走、ボスの凍結・後退への耐性。
