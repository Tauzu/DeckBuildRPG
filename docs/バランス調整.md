# バランス調整の記録

自動プレイ（`packages/sim`）でゲームを数百回ずつ遊ばせ、数値とルールを調整した記録。

## 自動プレイの使い方

```sh
npm run sim -- --players 1,2,4 --games 200 --bot smart,greedy --variants base,hand6+dmgBoss
```

| 引数 | 内容 |
|---|---|
| `--players` | 人数（カンマ区切り） |
| `--games` | 条件ごとのゲーム数 |
| `--bot` | `smart`（集落に近い敵を優先して戦う）、`greedy`（経験値の多い敵を優先）、`builder`（敵が迫るまで育成を優先）、`passive`（戦わない） |
| `--variants` | 試す候補（`packages/sim/src/variants.ts`）。`+` でつなぐと組み合わせ。`base` は今のデータそのまま |
| `--seed` | 最初のシード値 |

- 結果は表で表示され、`sim-output/` に CSV と JSON も出る。
- 手番ごとの「手札で出せる最大ダメージ」は `npx tsx src/diag.ts --variants base`（`packages/sim` で実行）。

## 2026-11-09 1人用の調整

### 調整前の状態

- 勝率 0%（どのボットでも）。魔竜に一度も挑めずに負ける。
- 最初のレベルアップは平均で手番15、1ゲームのレベルアップは2回程度（「レベルアップがなかなかできない」という感想と一致）。

### 原因

手番ごとに「手札で出せる最大ダメージ」を測ると、**ゲームの最初から最後まで 3 前後のまま伸びない**。

1. **戦利品でデッキが薄まる**：倒した敵がすべてデッキに入るため、終盤は約50枚のうち3割が戦利品・呪いになる。
2. **手札5枚では英雄を2人ほどしか出せない**：英雄1人に食料1枚が必要なため。
3. **魔竜の生命力25は1回の攻撃では届かない**：手札1回分の最大ダメージは、うまくいっても15前後。

### 試した候補（1人、smart ボット、150〜200ゲーム）

| 候補 | 勝率 | 敗因（耐久値／魔竜到達） | レベルアップ回数 | 最初のレベルアップ |
|---|---|---|---|---|
| 調整前 | 0% | 85%／15% | 2.4 | 手番15 |
| 手札6枚 | 0% | 14%／86% | 5.4 | 手番13 |
| 手札6枚＋魔竜の生命力10 | 17% | 11%／73% | 5.3 | 手番13 |
| 手札6枚＋魔竜のダメージが残る | 7% | 10%／83% | 5.1 | 手番13 |
| 戦利品をデッキに入れない＋手札6枚＋魔竜のダメージが残る | 78% | 0%／22% | 7.2 | 手番11 |
| **戦利品の売却＋手札6枚＋魔竜のダメージが残る** | 67% | 0%／33% | 6.9 | 手番12 |
| 上に加えて必要経験値 2／4 | 71% | 0%／29% | 9.5 | 手番7 |
| 上に加えて魔竜の生命力30（**採用**） | 43〜53% | 0%／50%前後 | 9.7 | 手番7 |

### 採用した変更

| 項目 | 変更前 | 変更後 | 種類 |
|---|---|---|---|
| 手札の枚数 | 5 | **6** | 数値 |
| 必要経験値（Lv1→2／Lv2→3） | 3／5 | **2／4** | 数値 |
| 魔竜の生命力（1／2／3／4人） | 25／30／35／40 | **30／35／40／45** | 数値 |
| 魔竜に与えたダメージ | 残らない | **残る** | ルール |
| 戦利品 | ずっとデッキに残る | **集落を訪れた手番の終わりに、手札にあれば売却されて消える** | ルール |

### 採用後の結果（1人、200ゲーム）

| ボット | 勝率 | S／A／B | レベルアップ回数 | 最初のレベルアップ | 1ゲームの手番 |
|---|---|---|---|---|---|
| smart | 43% | 39%／5%／0% | 9.7 | 手番7 | 約40 |
| greedy | 49% | 45%／4%／0% | 9.8 | 手番7 | 約40 |
| builder（慎重） | 24% | 12%／7%／5% | 8.6 | 手番10 | 約39 |
| passive（戦わない） | 0% | — | 0 | — | 15 |

- 計画書の目標（勝率40〜60%）に収まった。積極的に戦うほど勝ちやすく、戦わないと必ず負ける。
- 負けるときはほぼ「魔竜の到達」。魔竜を削り切れるかどうかが最後の山場になっている。

## 2026-11-09 追加の検討（無料の英雄枠・吟遊詩人・撃破直後のレベルアップ）

検討した3つの案。設定で切り替えられる。**3つすべてを採用し、手札5枚＋魔竜の生命力+5で釣り合いを取った**（下の「採用した変更（2回目）」）。

| 案 | 候補名 | 設定 |
|---|---|---|
| 食料がなくても英雄を1人出せる | `free1` | `setup.freeHeroSlots: 1` |
| 吟遊詩人 Lv1 の村効果を1枚→2枚ドロー | `bard2` | heroes.json の `hero_bard_1` |
| 敵を撃破した直後にもレベルアップ・転職できる（戦った英雄も対象） | `lvBattle` | `setup.levelUpAfterBattle: true` |

### 結果（smart ボット、1人は200ゲーム、2人・4人は150ゲーム）

| ＋3つすべて＋魔竜の生命力+10 | 86% | | | 手番5.0 | 11.4 |
| 手札5＋3つすべて | 71% | | | 手番5.9 | 10.7 |

- `free1` の効果がとびぬけて大きい（1人 49%→93%）。手札1枚ぶん以上の強さがある。
- `bard2` は小さめ（+7ポイント）。`lvBattle` は最初のレベルアップを2手番早め、勝率も +11ポイント。
- 3つすべて入れて手札6のままだと簡単すぎる（1人98%）。手札5に戻し、魔竜の生命力を+5（1人35）にすると1人52%で目標内。
- 手札の枚数は人数が増えたときに強く効く（3つすべて入れたとき、2人で手札6なら82%、手札5なら7%）。
- 初期デッキは10枚（若者3・黒パン5・棍棒2）。手札5なら2回でちょうど1周、手札6だと2回目は4枚＋シャッフル後の2枚になる。

## 残っている課題

### 2人以上の調整（要相談）

採用した数値のまま2人・4人で遊ばせると、勝率はほぼ0%（2人 7%、4人 0%）。

- 敵は1人の手番ごとに進むため、4人だと1人あたりの手番は約13回しかなく（1人用は約40回）、デッキが育つ前に集落が落ちる。
- 解決には次のような方向がある。どれを選ぶかでゲームの感触が大きく変わるため、相談して決めたい。
  1. 敵の進軍を「全員の手番が終わるごと（1ラウンドに1回）」に戻す
  2. 手番ごとに進軍するが、新しい敵の公開は1ラウンドに1回にする
  3. 人数が多いときは集落の耐久値を大きく増やし、敵の山札を減らす（数値だけで合わせる）

### その他

- S評価が勝ちの大半を占める（撃破すると進軍しないため、集落がほとんど傷つかない）。評価の基準は後で見直す。
- 1ゲームの手番が約40回と長め。遊んでみて長すぎるようなら、敵の山札を減らす。
