# FOODIE QUEST 収益化ロードマップ

> 作成：2026-11-27。方針は「**小さく始めて、数字を見てから次に進む**」。
> 金額・手数料・各サービスの規約は作成時点の目安。始める前に、それぞれの公式の案内で確かめる。

---

## 1. 結論（3行）

1. **まず英語化し、無料のブラウザ版のまま海外の人に遊んでもらう**（itch.io ＋ 投げ銭）。お金より先に「遊んだ人の数」と「感想」を集める。
2. 反応がよければ、**ブラウザゲームのサイト（CrazyGames など）に出して広告収益**を得る。月数千円が最初の目標。
3. 並行して **Steam のストアページを作り、ウィッシュリストを集める**。数が集まったら、ブラウザ版を体験版として残し、**Steam で買い切り版（$5.99 前後）を出す**。中国語（簡体字）はこの段階で入れる。

いきなり Steam で売らない理由：ストアページは「見つけてもらう仕組み」が弱く、知られていないゲームはほぼ売れない。先にブラウザ版で、面白いかどうかと、どの国の人が遊ぶかを確かめる。

## 2. 今の手札（強みと弱み）

| | 内容 | 収益化への意味 |
|---|---|---|
| 強み | ブラウザですぐ遊べる（インストール不要） | 試してもらう敷居が低い。ブラウザゲームのサイトに出せる |
| 強み | 1〜4人の協力プレイ、招待リンク | 「友だちを誘う」ことで自然に広がる。協力型のデッキビルドは数が少ない |
| 強み | 「英雄は食料を食べないと戦えない」という食べ物の題材、ドット絵、自作の曲 | 一言で説明でき、見た目で覚えてもらえる。曲はサウンドトラックとして売れる |
| 強み | 危険度・実績・図鑑など、繰り返し遊ぶ仕組みがある | 買い切りの値段に見合う遊ぶ量がある |
| 強み | 1人用は画面だけで動く（サーバー不要） | ブラウザゲームのサイトに静的ファイルとして置ける |
| 弱み | 日本語だけ | 海外にはまだ出せない（→ 4章） |
| 弱み | Render 無料枠で、開くまで1分かかることがある | 初めての人はその間に帰る。人が来る前に直す（月 $7 程度の有料プランか、1人用を別の場所に置く） |
| 弱み | 外部のテストプレイがまだ。2人以上だと長い・易しい | 広める前に、知らない人が最後まで遊べるかを確かめる |
| 弱み | 1プレイ20〜40分 | ブラウザゲームのサイトの客層（短く遊ぶ）とはややずれる。最初の数分の面白さが大事 |
| 弱み | 遊ばれた数を測る仕組みがない | どこから人が来たか、どこで辞めたかが分からない（→ 段階0） |

## 3. ロードマップ

各段階に「次に進む条件」を付ける。満たさなければ、先に進まずに直す。

### 段階0：準備（〜2週間、費用 0円）

- [ ] **テストプレイ**（進捗.md の「次にやること」）。知り合い数人に、説明なしで遊んでもらい、迷った所をメモする
- [x] **遊ばれた数を測る**：GoatCounter（Cookie を使わない無料の計測）に「開いた」「遊び始めた（1人・協力）」「最後まで遊んだ（勝ち・負け）」を送る仕組みを入れた（`client/src/analytics.ts`）。プライバシーの説明も1行出す。GoatCounter（foodie-quest）につないだ
- [x] **感想の入口**：タイトル画面に「感想を送る」（Google フォーム）
- [x] **応援の入口**：タイトル画面の隅に「作者を応援する」（https://ko-fi.com/tauzu ）
- [x] **文言を言語ごとに分けられる形にする**（4.3 の手順1）。`client/src/i18n.ts`・`locales/`。画面の文言はすべて英語にした（`?lang=en`）。英語を自動で選ぶようにして公開した
- [x] 名前の確認：「FOODIE QUEST」が他のゲームや商標とぶつからないか、Steam・itch.io・特許庁の検索（J-PlatPat）で見ておく
  - 2026-11-28 にネットで調べた範囲：「FOODIE QUEST」という名前のゲームは Steam・itch.io・App Store では見つからなかった。似た名前は、小さな個人作の「Food Quest」（itch.io のゲームジャムなど）と、Steam の「Foodie Tour」（3つ並べるパズル）。アメリカの商標で近いのは「FOOD QUEST」（登録番号 5631809、第41類：料理のテレビ番組。ゲームではなく、失効と書くサイトもある）。日本の J-PlatPat は自分で検索する（称呼「フーディークエスト」、第9類・第41類・第28類）。法律の判断ではないので、売り出す前に気になれば専門家に聞く

**次に進む条件**：知らない人が、説明なしでチュートリアルを終えられる。

### 段階1：英語版を無料で出す（1〜2か月、費用 0〜数千円）

- [x] 英語化（4章）。英語の題名・一言の紹介（例：*A co-op deckbuilder where your heroes need food to fight.*）
- [x] **itch.io に公開**（2026-11-27、https://tauzu.itch.io/foodie-quest ）（zip と作品ページの文は `docs/itch.io掲載.md`）：ブラウザで遊べる形 ＋「Pay what you want（好きな額を払う）」。itch.io は手数料の割合を自分で決められる
- [ ] 紹介用の素材を作る：30秒の動画、動く GIF を3つ、スクリーンショット5枚（英語の画面で）
- [ ] 海外の掲示板・SNS で告知（5章）。Discord のサーバーを作り、感想を集める
- [ ] サーバーの1分待ちを解消する

**目標**：遊んだ人 1,000人、最後まで遊んだ人の割合 20%以上、最初の投げ銭。
**次に進む条件**：「また遊びたい」「友だちとやりたい」という感想が自然に出てくる。最後まで遊ぶ割合が低ければ、最初の5分を直す。

### 段階2：ブラウザゲームのサイトで広告収益（2〜4か月目、費用 0円）

- [ ] **CrazyGames** に出す：応募して審査を受ける。通れば、サイトの広告の収益が分配される。サイトの SDK（広告・読み込みの合図）を組み込む必要がある
  - 広告は「ステージの合間」「負けたあとの続き」だけに出す。遊んでいる途中には出さない
  - 1人用は静的ファイルとして置き、協力プレイは今のサーバーにつなぐ
- [ ] 他の候補：GameDistribution、Newgrounds、国内なら PLiCy・ふりーむ!（国内は収益より日本の知名度のため）
  - Poki は審査が厳しく、独占を求められることが多い。CrazyGames で数字が出てから考える
- [ ] サイトで遊ばれた数から、**どの国の人が多いか**を見る（4.1 の3番目以降の言語を決める材料）

**目標**：月の広告収益 数千円。サイトの評価（高評価の割合）を保つ。
**次に進む条件**：毎日安定して遊ばれる。評価が低ければ、どこで辞めているかを見て直す。

### 段階3：Steam のストアページとウィッシュリスト（3か月目から並行、費用 約1.5万円）

- [ ] Steamworks に登録（登録料 $100。売上が $1,000 を超えると戻ってくる）。税の書類（W-8BEN）を出す。日米租税条約で、アメリカでの源泉徴収は 0% にできる
- [ ] ブラウザ版を PC アプリにする（Electron か Tauri で包む）。協力プレイは今のルームコード方式のままでよい（Steam の友だち招待は後回し）
- [ ] **ストアページを早めに公開**し、ウィッシュリスト（欲しいものリスト）を集める。itch.io・サイト版・SNS からストアページへ誘導する
- [ ] **Steam Next Fest**（年3回ほどある体験版の祭り）に、ブラウザ版と同じ内容の体験版で参加する。ウィッシュリストが一番増える機会
- [ ] Steam らしさを足す：Steam の実績（今の22種をそのまま使える）、クラウドセーブ

**目標**：ウィッシュリスト 2,000件（目安。多いほど発売時に Steam のおすすめに載りやすい）。
**次に進む条件**：ウィッシュリストが毎週増え続けている。

### 段階4：Steam で買い切り版を発売（6か月目以降）

- [ ] **値段**：$5.99 前後（日本は Steam のおすすめの地域価格を使う）。発売時に 10〜20% 引き
- [ ] **無料版との差**：ブラウザ版は「チュートリアル＋ステージ1〜2」の体験版にする。製品版はステージ3〜5・危険度・図鑑・実績。今ブラウザ版で全部遊べている人への配慮として、切り替える前に告知し、引き継ぎコードは製品版でも読めるようにする
- [ ] **簡体字中国語**をこの時点で入れる（4章）
- [ ] **サウンドトラック**を有料の追加コンテンツ（$2.99 程度）として出す。曲は自作なのでそのまま出せる
- [ ] 発売後：追加のステージ・英雄を無料のアップデートで足し、そのたびに告知する（話題が切れないように）

**目標（小さく）**：最初の1年で 300〜500本。$5.99 × 400本 ≒ $2,400、Steam の手数料 30% を引いて 約$1,700（約25万円）。

### 段階5：続けるかを決める

数字を見て、次のどれかを選ぶ。

- 売れている → 有料の大型追加（新しいボスと英雄のセット）、他の言語、スマートフォン版（ストアの登録料・審査の手間を見てから）
- 売れていないが評価は高い → 知名度の問題。配信者への声かけを増やし、セールに参加する
- 評価が低い → ゲームそのものを直す。広告や宣伝を増やしても効かない

## 4. ローカライズ（翻訳）

### 4.1 どの言語から始めるか

| 順 | 言語 | 理由 | 入れる段階 |
|---|---|---|---|
| 1 | **英語** | どの国の人もまず英語で探す。ブラウザゲームのサイト・Reddit・itch.io の中心 | 段階1 |
| 2 | **簡体字中国語** | Steam の利用者の言語で英語と並んで多い。デッキビルドの人気が高い。機械翻訳は嫌われやすいので、母語の人に見てもらう | 段階4（Steam 発売時） |
| 3 | **繁体字中国語** | 簡体字から変換して直す手間は小さい。台湾は日本のゲームへの関心が高い | 段階4 のあと |
| 4〜 | 韓国語・ブラジルのポルトガル語・ドイツ語・ロシア語・スペイン語 から選ぶ | 決め打ちしない。CrazyGames の国別の数と、Steam のウィッシュリストの国別の数（Steamworks で見られる）で多い順に足す | 段階5 |

言語を増やすたびに、テストと文言の手直しの手間が増える。**1つ足すごとに、その国からの数字が増えたかを確かめてから次へ**。

### 4.2 翻訳の量と費用

- 画面の文言は、`text.ts` に集めたもの（約5,000字）のほか、各画面の部品・実績・図鑑・カードのデータ（`data/*.json`）にもある。合わせて **2〜3万字ほど**（段階0で文言を集めたときに正確に数える）
- 翻訳会社に頼むと1言語で数十万円かかる。小さく始めるため、次のやり方にする
  1. Claude などで下訳する（用語集を先に作り、カード名・効果の言い方を統一する）
  2. Discord や Reddit で、その言語を母語とする遊び手に見てもらう（お礼はゲーム内のクレジットと製品版のキー）
  3. 製品版の前だけ、要の部分（チュートリアル・カードの効果）を有料で確かめてもらう（Fiverr などで数万円）
- **食べ物の言葉遊び**はそのまま訳さず、その言語で面白い名前にする（英語なら food の駄洒落）。用語集に元の意図を書いておく

### 4.3 作り方の手順

1. 文言を言語ごとのファイル（例：`locales/ja.json`・`locales/en.json`）に移し、画面は鍵（`"error.notEnoughGold"` など）で引く。カードのデータは名前と説明を鍵にし、文言は言語ファイルに置く。設計書 4.3 の「文言は1か所にまとめる」をそのまま広げる形
2. 数の入る文（「金が{n}足りない」）、単数と複数、語順の違いに対応する（`Intl.PluralRules`）
3. 言語の選び方：最初はブラウザの言語で決め、タイトル画面で切り替えられるようにする。協力プレイでは、各自が自分の言語で見る（サーバーは鍵だけを送る）
4. **長さの確認**：英語やドイツ語は日本語より長くなる。カード・ボタンからはみ出さないか、全画面を英語で見て回る。テストに「全言語で鍵の抜けがない」確認を足す
5. **フォント**：今の DotGothic16 は英語と日本語は出るが、簡体字・繁体字・韓国語の字が足りない。中国語・韓国語を入れるときは、同じドット絵の雰囲気で多言語に対応したフォント（Fusion Pixel Font など。利用の条件を確かめる）に切り替える
6. 画像の中に文字を入れない（入っているものは、文字を画像の外に出す）

## 5. 知名度を上げる戦略

### 5.1 考え方

- お金をかけた広告はしない。**作っている様子を見せ続ける**ことと、**遊んだ人が誰かを誘う仕組み**で広げる
- 告知は「完成してから一度だけ」ではなく、**少しずつ、何度も**。毎回、動く画面（GIF・短い動画）を付ける
- 一番伝えたい一言を決めて、どこでも同じ言い方をする
  - 英語：*A co-op deckbuilder where your heroes need food to fight.*
  - 日本語：「英雄は、食べないと戦えない。協力型デッキビルドRPG」

### 5.2 ゲームの中の仕組み（広がるきっかけ）

| 仕組み | 内容 | 手間 |
|---|---|---|
| 招待リンク | すでにある。リンクを貼ったときの見た目（`og-invite.png`）を英語版でも用意する | 小 |
| 結果の共有 | 勝ったあとに「ステージ・危険度・手番・評価」を絵文字の短い文と画像にしてコピーできるボタン。SNS に貼りやすく | 小〜中 |
| 今日の挑戦 | 計画書 7章の候補。全員が同じ条件で遊び、結果を共有する。毎日話題になる | 中〜大（段階3以降） |
| クレジット | 翻訳や感想をくれた人の名前をゲーム内に載せる。協力した人が広めてくれる | 小 |

### 5.3 場所ごとの告知

| 場所 | 対象 | やること | 段階 |
|---|---|---|---|
| X（旧Twitter） | 日本・海外 | 週1〜2回、GIF付きで開発の様子。英語は `#indiedev` `#gamedev`、土曜は `#screenshotsaturday`。日本語は `#indiegame` `#ゲーム制作` | 段階0〜 |
| Reddit | 英語圏 | r/deckbuildinggames、r/WebGames、r/playmygame、r/indiegames。「遊んで意見がほしい」という形で出す（宣伝だけの投稿は嫌われる）。各掲示板の決まりを読んでから | 段階1〜 |
| itch.io | 英語圏 | 開発日誌（devlog）を更新のたびに書く。itch.io の新着に出る | 段階1〜 |
| Discord | 全体 | 自分のサーバー（感想・翻訳の協力・協力プレイの仲間探し）。デッキビルドの集まりにも顔を出す | 段階1〜 |
| YouTube・TikTok の短い動画 | 全体 | 「食料が足りず英雄が出せない」「ボス登場」など、見て分かる場面を15〜30秒で | 段階1〜 |
| 配信者・動画投稿者 | 英語圏・日本 | デッキビルドや協力ゲームを遊ぶ中小の配信者に、メールで体験版（のち製品版のキー）を送る。大物より、視聴者数が数百〜数千の人のほうが返事をくれやすい。協力プレイは「配信者と視聴者で遊べる」と伝える | 段階2〜 |
| Steam | 全体 | ストアページ、Next Fest、発売後のセール。Steam の中の告知（イベント）をアップデートのたびに出す | 段階3〜 |
| bilibili・微博 | 中国 | 中国語版を入れてから。中国語の紹介動画を1本。母語の協力者に手伝ってもらう | 段階4〜 |
| 国内 | 日本 | ふりーむ!、PLiCy、ゲーム制作のコンテスト・インディーゲームの展示会（オンライン応募のもの） | 段階1〜 |

### 5.4 続けるための目安

- 週に使う時間：開発 7割・告知 3割
- 告知のたびに、計測で「その日に増えた人の数」と「どこから来たか」を見る。効いた場所に時間を寄せる

## 6. 収益の柱の比べ方

| 柱 | 始めやすさ | 見込み | 注意 |
|---|---|---|---|
| 投げ銭（Ko-fi・itch.io） | ◎ すぐ | 小（月数百〜数千円） | 「応援してくれる人」がいて初めて入る |
| ブラウザゲームのサイトの広告 | ○ 審査あり | 小〜中（遊ばれる数しだい） | 広告の出し方で評価が下がる。長いゲームは不利 |
| Steam の買い切り | △ 準備が多い | 中（このロードマップの本命） | 知られていないと売れない。先にウィッシュリスト |
| サウンドトラック | ○ Steam・Bandcamp | 小 | ゲームが好かれてから売れる |
| 有料の追加コンテンツ | △ 作る量が多い | 小〜中 | 本編が売れてから |

**やらないこと**：ガチャ・スタミナ・遊んでいる途中の広告・個人情報を集める広告。小さなゲームの評判を一番下げるもの。

## 7. お金と手続き

| 項目 | 内容 |
|---|---|
| 最初にかかるお金 | 段階0〜2：ほぼ0円（独自ドメインを取るなら年 2,000円ほど）。サーバーを有料にするなら月 $7 程度。段階3：Steam の登録料 $100 |
| 税金 | 会社員で、副業の所得（売上から経費を引いた額）が年20万円以下なら所得税の確定申告は不要（住民税の申告は必要）。それを超えたら確定申告。収入と経費（サーバー代・登録料・翻訳の謝礼）の記録を、最初の1円からつけておく |
| 海外の売上 | Steam・itch.io は税の書類（W-8BEN）を出すと、アメリカでの源泉徴収を 0% にできる。受け取りは日本の銀行口座か PayPal |
| 規約 | 各サイトの規約（独占の有無・広告の決まり・年齢の表示）を出す前に読む。プライバシーの説明を用意する（計測・広告を入れるとき） |
| 素材の権利 | 曲・絵は自作。フォント（DotGothic16 は OFL で商用可）など、他の人が作ったものは、使い方の条件を一覧にしておく |

## 8. 次の一歩

1. テストプレイ（すでに予定どおり）
2. 計測・感想の入口・投げ銭のリンクを入れる
3. 文言を言語ファイルに分ける → 英語化
4. itch.io に英語版を出し、Reddit と X で告知

段階を終えるたびに、この文書の目標と実際の数字を書き足す。
