# 感想フォームの質問（Google フォーム）

> 作成：2026-11-27。フォームは1つのまま、英語と日本語を並べて書く（海外の人も日本の人も同じフォームに答える）。
> フォーム：https://docs.google.com/forms/d/e/1FAIpQLSeG5C7dhUcwJMeHlX1VoITZpP7Zt5U43RX6CC31Pem1nR5jJg/viewform （`client/src/links.ts` の `FEEDBACK_URL`）

## フォームの設定

- タイトル：`FOODIE QUEST – Feedback / 感想`
- 説明：

```
Thanks for playing! Every answer is optional and takes about 2 minutes.
遊んでくれてありがとうございます！どれも答えなくて大丈夫です（2分ほど）。
```

- 設定 → 回答：**メールアドレスを収集しない**、**ログインを必須にしない**（答える手間を減らす）
- 質問はどれも「必須」にしない

## 質問

上から順に入れる。種類は Google フォームの質問の種類。

| # | 種類 | 質問 | 選択肢 |
|---|---|---|---|
| 1 | 選択式（ラジオボタン） | How did you play? / 遊び方 | Solo / 1人 ・ Co-op (2–4 players) / 協力プレイ ・ Both / 両方 |
| 2 | 選択式 | Where did you play? / どこで遊んだ？ | itch.io ・ foodie-quest.onrender.com ・ Other / その他 |
| 3 | 選択式 | How far did you get? / どこまで進んだ？ | Quit during the tutorial / チュートリアルの途中まで ・ Cleared the tutorial / チュートリアル ・ Stage 1 ・ Stage 2 ・ Stage 3 ・ Stage 4 ・ Stage 5 |
| 4 | 均等目盛（1〜5） | How fun was it? / 面白さ | 1 = Not fun / つまらない、5 = Very fun / とても面白い |
| 5 | 選択式 | Were the rules clear after the tutorial? / チュートリアルのあと、ルールはわかった？ | Yes / わかった ・ Mostly / だいたい ・ No / わからなかった |
| 6 | 選択式 | Difficulty / 難しさ | Too easy / 簡単すぎ ・ Just right / ちょうどよい ・ Too hard / 難しすぎ |
| 7 | 段落 | What was the most fun? / 一番楽しかったところは？ | |
| 8 | 段落 | What was confusing or frustrating? / わかりにくかった・イライラしたところは？ | |
| 9 | 段落 | **Ideas for new cards, heroes, enemies or bosses** (name + what it does)<br>**ほしいカード・英雄・敵・ボスの案**（名前と、どんな効果か） | 説明に例を書く：`e.g. "Picnic Basket" – Food 2, draw 1 card / 例：「お弁当」食料2、カードを1枚引く` |
| 10 | 選択式 | Would you buy a bigger version on Steam (around $5)? / Steam で、内容を増やした版（500円くらい）が出たら買う？ | Yes / 買う ・ Maybe / たぶん ・ No / 買わない |
| 11 | 段落 | Anything else? / ほかに何でも | |
| 12 | 記述式 | (Optional) Your name or handle, if you'd like a reply or credit / （任意）返事や、案を採用したときに名前を載せてほしければ、名前か SNS の名前 | |

- 9 で案を採用したら、12 の名前を devlog やゲームのお礼の欄に載せる（遊んだ人が案を出す気になる）
- 3・5 は、チュートリアルのどこで人が離れるかを見るため
- 10 は、Steam に進むか（`docs/収益化ロードマップ.md` 段階3）を決める材料

## 答えを見る

- フォームの「回答」タブ → スプレッドシートにつなぐと、並べて読みやすい
- 読んだ意見は `docs/進捗.md` に書き、直したら devlog で「直しました」と書く
