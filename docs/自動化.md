## 統計の自動化

仕組み：`.github/workflows/stats.yml` が毎朝 `scripts/stats-report.mjs` を動かす。

- 数えるもの：開いた人数、遊び始めた人数（1人 / 協力）、最後まで遊んだ人数（勝ち / 負け）、ステージごとの数、どこから来たか（参照元の上位10）
- 日の区切りは日本時間の0時
- リポジトリは公開なので、Issue の数も誰でも見られる（人数だけで、個人の情報は入らない）

### 1. GoatCounter で API の鍵を作る

1. https://foodie-quest.goatcounter.com にログインする
2. 右上の自分の名前 → **API**
3. 新しい鍵を作る。名前は `github-actions` など。権限は**統計を読むだけ**のものを選ぶ（書き込みや設定の変更の権限は要らない）
4. 表示された鍵をコピーする（**チャットには貼らない**）

### 2. GitHub に鍵を登録する

1. GitHub のリポジトリ → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret**
3. Name：`GOATCOUNTER_TOKEN`、Secret：コピーした鍵 → **Add secret**

### 3. 試しに動かす

1. GitHub のリポジトリ → **Actions** → 左の **daily-stats** → **Run workflow**（日付は空でよい）
2. 終わったら **Issues** に「毎日の数（GoatCounter）」ができ、前日の数がコメントされている
3. その Issue を見ている（Watch / Subscribe）と、毎朝のコメントがメールで届く。作った Issue は自動で見ている状態にならないことがあるので、Issue の右の **Subscribe** を押しておく

### 手元で動かす

```sh
GOATCOUNTER_TOKEN=... node scripts/stats-report.mjs 2026-11-28
```
